# Documentation

| Folder | Contents |
| --- | --- |
| `adr/` | Architecture Decision Records. One file per decision, never edited after acceptance; superseded by a new ADR. |
| `architecture/` | How the system works: ingestion pipeline, data model, module boundaries, query and alerting flows. |
| `guides/` | Task-oriented documentation for operators and developers: install, configure, deploy, upgrade, develop. |
| `integrations/` | One page per monitored platform or database, paired with the collector config in `/integrations`. |
| `api/` | Reference for the REST API and the OTLP endpoints Veyra exposes. |

Write documentation in Markdown. Diagrams use Mermaid so they render on GitHub without tooling.
